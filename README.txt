UPWIND — HOSTING
Part of Preconnect (https://charge-the-line.github.io/). This folder is the whole app:
index.html, preconnect-core.js, manifest.json, sw.js, icon-192.png, icon-512.png, fonts/
(plus tests/, TESTING.md and CLAUDE.md, which do not affect the app).

GitHub Pages serves the main branch root of the charge-the-line/upwind repository at
https://charge-the-line.github.io/upwind/. Committing to main deploys within a minute or two.
Every release bumps APP_VERSION in index.html and CACHE in sw.js together.
